Hero Focus Picker

Load the converted .webp files from static/images/hero/ to preview exactly how each one gets cropped and animated on the homepage - including the real hero title/description/button text, the readability gradient/dim, and the cave-silhouette motif overlay. Use the screen-size dropdown below to switch between the site's 3 supported breakpoints (like VS Code's device toolbar); each size can have its own crop/ zoom/pan-or-zoom-animation - click on the photo (or drag the sliders) to set it, and tablet/phone start out inheriting the desktop values until you tick "Custom for this size" for that size. You can also mirror a photo horizontally/vertically, and exclude it entirely from a given screen size ("Visible at this size"). Then copy the generated YAML per photo into data/hero_images.yaml. Nothing here is uploaded anywhere - images are only read locally in your browser.
