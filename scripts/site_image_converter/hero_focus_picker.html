Hero Focus Picker

If you started this via run_hero_picker.bat, the panel below lets you pick, add, or delete a real site hero photo and save changes straight to data/hero_images.yaml. Opened directly as a file instead (no server running)? Everything further down still works in offline/preview mode: load the converted .webp files from static/images/hero/ to preview exactly how each one gets cropped and animated on the homepage - including the real hero title/description/button text, the readability gradient/dim, and the cave-silhouette motif overlay. Each photo has its own "Preview at" screen-size control right in its editor, matching the site's 3 supported breakpoints (like a device toolbar); each size can have its own crop/zoom/pan-or-zoom-animation - click on the photo (or drag the sliders) to set it, and tablet/phone start out inheriting the desktop values until you tick "Custom settings for this size". You can also mirror a photo horizontally/vertically, and hide it below a chosen breakpoint. Nothing here is uploaded anywhere - offline-mode images are only read locally in your browser.
